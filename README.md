# ระบบจัดการสั่งซื้อยางประจำวัน (Daily Tire Purchasing & Expense App)

ระบบช่วยจัดการการสั่งซื้อยางประจำวัน เชื่อมโยงข้อมูลคำสั่งซื้อใหม่จาก **BigSeller (`status=new`)** ตามรอบเวลาตัดรอบ **12.00 น. (เมื่อวาน) - 08.00 น. (วันนี้)** เพื่อให้พร้อมสำหรับการสั่งของกับร้านซับ (Supplier) ในช่วงเวลา **08.30 - 12.00 น. ของทุกวัน** โดยมีโครงสร้างตารางตรงตาม [Google Sheets](https://docs.google.com/spreadsheets/d/1kKYSU-vcSVh3G8wQMOSO3HF42zA2yJ33dmlxwjk348E/edit?gid=391311781#gid=391311781) ของคุณแบบ 100%

---

## ✨ จุดเด่นและฟังก์ชันหลักของระบบ

1. **ดึงข้อมูลออเดอร์จาก BigSeller อัตโนมัติ:**
   - คัดกรองเฉพาะคำสั่งซื้อที่เข้ามาในช่วง **12.00 น. (เที่ยงเมื่อวาน) ถึง 08.00 น. (เช้าวันนี้)**
   - ดึงข้อมูลอัตโนมัติทุกเช้าเวลา **08.00 น.** (ก่อนเวลาเริ่มสั่งของ 08.30 น.)
   - มีปุ่ม **"ดึงจาก BigSeller"** ให้กดดึงข้อมูลสดได้ตลอดเวลา
   - ปลอดภัยด้วยระบบ Browser Profile ล็อกอินบัญชี BigSeller ครั้งแรกเพียงครั้งเดียว ระบบจะจำ Session ไว้ตลอด

2. **ระบบจัดการ ซับ (Supplier) และราคาต้นทุน พร้อมระบบช่วยจำ (Memory & Mapping):**
   - มีช่องให้เลือก/พิมพ์ร้านซับ และราคาต้นทุน/เส้น ได้อย่างอิสระ
   - **ปุ่มลัดตรวจเช็กราคา:** มีปุ่มคลิกเพื่อเปิดหน้าคำสั่งซื้อจริงใน Shopee / Lazada เพื่อเทียบราคาได้ทันที
   - **ระบบจำประวัติอัจฉริยะ:** หากยางรุ่นใดเคยสั่งกับซับไหนและราคาเท่าใด ระบบจะจดจำและแนะนำ (Auto-fill) ให้อัตโนมัติในครั้งถัดไป ไม่ต้องเสียเวลากรอกซ้ำ

3. **แนบสลิปโอนเงิน & บันทึกค่าใช้จ่าย (รองรับทั้งคอมและมือถือ):**
   - คำนวณยอดรวมจ่ายค่ายางให้อัตโนมัติ: `(จำนวน × ราคา/เส้น) + ค่าขนส่ง`
   - **ใช้งานผ่านมือถือ:** สามารถเชื่อมต่อ Wi-Fi เดียวกันแล้วสแกน QR Code เพื่อเปิด App บนโทรศัพท์มือถือ กดถ่ายรูปสลิปจากกล้องมือถือแล้วแนบเข้าออเดอร์ได้ทันที
   - แกลเลอรีสลิปโอนเงินประจำวัน ช่วยให้ตรวจสอบยอดโอนย้อนหลังได้สะดวก

4. **บันทึกลง Google Sheets อัตโนมัติ:**
   - ส่งข้อมูลลงใน Google Sheet ของคุณตามคอลัมน์ A ถึง L เป๊ะๆ:
     `[สถาณะ | ร้านค้า | เลขออเดอร์ | รายการสินค้า | จำนวน | หน่วย | ซับ | ว่าง | ราคา/เส้น | ค่าขนส่ง | shopee/lazada | ยอดรวมจ่ายค่ายาง | ลิงก์สลิป]`
   - มีปุ่ม **"ส่งออก CSV"** สำหรับดาวน์โหลดไฟล์ไปเปิดใน Microsoft Excel หรือ Google Sheets ได้ทันที (รองรับภาษาไทย 100%)

5. **ระบบสถิติและฐานข้อมูลสินค้า (Analytics):**
   - **สินค้าขายดี (Top Best Sellers):** จัดอันดับยางรุ่นที่มียอดสั่งซื้อสูงสุด เพื่อใช้วางแผนสต็อก
   - **สินค้าที่ขาดตลาดบ่อย ๆ (Frequently Out of Stock):** บันทึกประวัติรายการที่ซับไม่มีของส่ง เพื่อให้รู้ล่วงหน้าว่ารุ่นใดขาดตลาดบ่อย
   - **สรุปยอดเงินแยกตามซับ:** รวมยอดเงินที่ต้องจ่ายให้แก่ร้านซับแต่ละเจ้าในแต่ละวัน

6. **เครื่องคิดราคาขายยาง & คำนวณกำไรหน้าร้าน (Storefront Tire Calculator):**
   - คำนวณราคาขายและกำไรสำหรับเสนอลูกค้าหน้าร้านหรือทาง LINE ได้ทันที
   - **สูตรคำนวณมาตรฐาน:**
     `ราคาขาย = ทุนยางรวม + ค่าแรงมือช่าง (เริ่มต้น 50 บ./เส้น) + กำไรที่ต้องการ + VAT 7% (ถ้ามี) + ค่ารถ`
   - **ค่ารถ (ช่องสุดท้ายก่อนรวมราคาขาย):** เลือกลักษณะคิดค่ารถได้ตามจริง ทั้งแบบต่อรอบการเรียก/ต่อซับ (เหมา), ต่อเส้น หรือส่งฟรี (0 บ.)
   - **เครื่องมือเสริมหน้าร้าน:**
     - แสดงราคาขายเฉลี่ยต่อเส้น (ฟรีค่าแรงช่าง)
     - เปรียบเทียบราคาด่วน 2 เส้น VS 4 เส้น (ชุด)
     - ปุ่มปัดเศษราคาขาย (หลัก 10, 50, 100) เพื่อให้แจ้งราคาหน้าร้านได้ง่าย
     - ปุ่ม **"คัดลอกข้อความส่ง LINE"** จัดรูปแบบข้อความพร้อมส่งให้ลูกค้าได้ใน 1 คลิก
     - พิมพ์ใบเสนอราคาหน้าร้าน (Print Quotation Slip)
     - บันทึกและเรียกดูประวัติการเสนอราคาล่าสุด

7. **รองรับการติดตั้งเป็นแอปมือถือและเดสก์ท็อป (Progressive Web App - PWA):**
   - ติดตั้งลงหน้าจอมือถือ (Android / iOS) และคอมพิวเตอร์ได้เหมือน Native App
   - มีปุ่ม **"📲 ติดตั้งแอป"** ที่มุมบน
   - หน้าเฉพาะกิจสำหรับเคาน์เตอร์หน้าร้าน: `/calculator.html` เปิดเต็มหน้าจอ โหลดเร็ว และรองรับการทำงานออฟไลน์ (Offline Support)

## 🚀 วิธีการเปิดใช้งานระบบ

### 1. เปิดโปรแกรมบนคอมพิวเตอร์
- ดับเบิลคลิกที่ไฟล์ **`start.bat`** ในโฟลเดอร์นี้
- ระบบจะเปิดเบราว์เซอร์ขึ้นมาที่หน้าเว็บ:
  👉 **`http://localhost:3838`**

### 2. เปิดใช้งานผ่านโทรศัพท์มือถือ (เพื่อถ่ายรูปสลิป)
1. เชื่อมต่อโทรศัพท์มือถือเข้ากับ Wi-Fi เดียวกันกับคอมพิวเตอร์
2. บนหน้าจอคอมพิวเตอร์ ให้กดปุ่ม **"เปิดบนมือถือ"** ที่มุมขวาบน
3. ใช้กล้องมือถือสแกน QR Code ที่แสดงขึ้นมา (หรือเปิด URL: `http://192.168.0.252:3838`)
4. คุณสามารถกดเลือกคำสั่งซื้อแล้วกดถ่ายรูปสลิปโอนเงินส่งเข้าคอมพิวเตอร์ได้ทันที!

## 🔑 การตั้งค่าการเชื่อมต่อครั้งแรก

### 1. เชื่อมต่อ BigSeller (ทำเพียงครั้งแรกครั้งเดียว)
1. ไปที่แท็บ **"ตั้งค่าระบบ & BigSeller"**
2. กดปุ่ม **"เปิดหน้าล็อกอิน BigSeller ครั้งแรก"**
3. หน้าต่าง Google Chrome จะเปิดขึ้นมา ให้คุณกรอกอีเมลและรหัสผ่านเข้าสู่ระบบ BigSeller ของคุณ
4. เมื่อล็อกอินสำเร็จ สามารถปิดหน้าต่างเบราว์เซอร์ได้เลย ระบบจะจดจำข้อมูลการเข้าสู่ระบบไว้ในเครื่องของคุณอย่างปลอดภัย

### 2. เชื่อมต่อ Google Sheets โดยอัตโนมัติ (Apps Script Webhook)
1. เปิดตาราง [Google Sheets ของคุณ](https://docs.google.com/spreadsheets/d/1kKYSU-vcSVh3G8wQMOSO3HF42zA2yJ33dmlxwjk348E/edit?gid=391311781#gid=391311781)
2. ไปที่เมนูด้านบน: **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดเดิมในนั้นออกทั้งหมด แล้วคัดลอกโค้ดสำเร็จรูปจากหน้า **"ตั้งค่าระบบ"** ใน App ไปวาง
4. กดปุ่มสีน้ำเงิน **"ทำให้ใช้งานได้ (Deploy)" > "การทำให้ใช้งานได้ใหม่ (New deployment)"**
5. เลือกประเภท **"เว็บแอป (Web app)"**
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
6. กด "ทำให้ใช้งานได้" แล้วคัดลอก **URL เว็บแอป** นำมาวางในช่อง `Google Apps Script Webhook URL` ใน App แล้วกด **"บันทึกการตั้งค่า"**
*(หลังจากนี้เมื่อกดปุ่ม "บันทึกลง Sheet" ข้อมูลจะถูกส่งลงตาราง Google Sheet ของคุณทันที)*
